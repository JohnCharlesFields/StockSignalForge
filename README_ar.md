منصة أبحاث أسهم مدعومة بالذكاء الاصطناعي، مبنية على إطار [HKUDS/Vibe-Trading](https://github.com/HKUDS/Vibe-Trading). تجمع الأسعار والأخبار وفرز مرشحي التراجع وتحليل الشركات ومراجعة المراكز والاختبارات التاريخية.

> **يركز المشروع أساساً على الأسهم الأمريكية وخيارات الأسهم المدرجة في الولايات المتحدة. لا تزال الأسهم الصينية من الفئة A وأسهم هونغ كونغ قيد التكييف، وليست مدعومة بالكامل.** وجود محول في الإطار الأصلي لا يعني اكتمال دعم البيانات والتقويم والإشارات والتحقق في هذا الفرع.

## نطاق الأسواق

| السوق | النطاق الحالي |
| --- | --- |
| الأسهم الأمريكية | مسار البحث الأساسي: المرشحون اليوميون والرسوم وبيانات الشركات والأخبار وقوائم المتابعة |
| خيارات الأسهم الأمريكية | بحث اتجاه Call/Put/الانتظار، وIV/Greeks المتاحة، وحساب يدوي لسيناريوهات عقودCall باستحقاق60–90يوماً والخروج، بحسب الصلاحيات وجودة البيانات |
| الأسهم الصينية A | قيد التكييف؛ لم يكتمل التحقق من المسار بأكمله |
| أسهم هونغ كونغ | قيد التكييف؛ لم يكتمل التحقق من المسار بأكمله |

المشروع مساعد بحثي ولا يضمن الأرباح أو توصيات شراء وبيع مؤكدة. لا يتصل بوسيط ولا يرسل أوامر تداول حقيقية تلقائياً. تجارب تنفيذSOXL محاكاة وليست خدمة تداول حي.

## الوظائف الأساسية

- ترتيب مرشحي التراجع، والمتابعة المستمرة، ومقارنة التوقعات بالنتائج اللاحقة.
- شموع الأسعار وبنية الاتجاه وعلامات البحث السببية، والشركات والقطاعات وسلاسل التوريد ومستويات المخاطر.
- بحث اتجاه الخيارات وتقلبها، ومقارنة سيناريوهات العقود والخروج بالأسعار المتاحة.
- أخبار مرتبة حسب الأهمية وآراء صناع المحتوى المستندة إلى نصوص أو ترجمات فعلية.
- قوائم المتابعة ومراجعة المراكز والإشارات الثلاثية ومؤشرات جودة الأحداث وGEX.
- أبحاث العوامل والاختبارات التاريخية والأدلة المستقبلية بحسب الإصدار والمهام اليومية وحداثة الذاكرة المؤقتة.

تبقى بياناتIV أوOI أو الحجم أو النص أو موعد الأرباح أو المكونات التاريخية المفقودة «غير معروفة»؛ لا تتحول إلى صفر أو أدلة مختلقة.

## البدء باستخدامDocker

استخدمDocker Engine/Compose أوDocker Desktop في وضع حاوياتLinux. نفذ الأوامر من جذر المستودع، ولا تستبدل ملف الإعدادات الخاص الموجود.

<div dir="ltr">

```powershell
if (!(Test-Path agent/.env)) { Copy-Item agent/.env.example agent/.env }
# Configure agent/.env locally before starting the application.
docker compose up -d --build vibe-trading
```

</div>

حرر `agent/.env` محلياً قبل التشغيل. افتح [المنصة](http://127.0.0.1:19090) و[فحص الصحة](http://127.0.0.1:19090/health).

<div dir="ltr">

```sh
docker compose logs --tail 100 vibe-trading
docker compose stop vibe-trading
```

</div>

يرتبط المنفذ افتراضياً بـlocalhost فقط. يتطلب الوصول البعيد مصادقة وOrigin موثوقاً محدداً.

### تحديث تثبيت موجود

انتظر اكتمال المسح والمعايرة والإثراء والمهام النشطة. أنشئ نسخة متسقة باستخدام واجهة النسخ الاحتياطي المباشر لـSQLite، واحتفظ بوحدات التخزين المسماة.

<div dir="ltr">

```sh
docker compose build vibe-trading
docker compose up -d --no-deps vibe-trading
```

</div>

لا تستخدم `docker compose down -v`. نسخ مستودعGit لا ينقل قواعد البيانات أو الذاكرة المؤقتة أو الإعدادات الخاصة أوCookies؛ يلزم ترحيلها بنسخة متسقة.

## البيانات والإعدادات الخاصة

| الإعداد | المتغيرات المحلية |
| --- | --- |
| نموذجAI | `LANGCHAIN_PROVIDER` و`LANGCHAIN_MODEL_NAME` وبيانات الاعتماد في`agent/.env` |
| GilData MCP | `GILDATA_MCP_URL` و`GILDATA_MCP_TOKEN` كل منهما منفصل؛ [دليل الربط](GILDATA_MCP.md) بالصينية |
| مصادر الأسعار الأخرى | مفاتيحك الخاصة وصلاحيات السوق المطلوبة |
| مصادقةAPI | `API_AUTH_KEY` |
| أدواتMCP الخارجية | `config/agent.example.json` و`config/mcp-client.example.json` |

GilData مصدر اختياري للأدلة، وليس علامة مشتركة أو ضماناً للأرباح. قد لا تشمل خطة أسعار الأسهم صلاحية خياراتOPRA؛ تحقق من تاريخ السعر والمصدر البديل.

لا توزع المفاتيح أو عناوينMCP الموثقة أوCookies أو قواعد البيانات أو بيانات الموردين التاريخية أو تسميات التدريب الخاصة. التحديث والتدريب الخلفيان يحتاجان إعداداً صريحاً؛ لا يتم تفعيل نموذج جديد تلقائياً.

## حدود الاحتمالات والاختبار التاريخي

درجات البحث، واحتمالات الأسهم المعايرة، ونسبة الصفقات ذات الربح الصافي، وalpha مقابلSPY، واحتمال ربح الخيار مقاييس مختلفة. قد يخسر الخيار رغم صحة اتجاه السهم بسبب العلاوة والفارق السعري وتناقص القيمة الزمنية وتغيرIV. جداول السيناريوهات ليست قيماً متوقعة مرجحة باحتمالات.

علامات البحث ليست دليلاً على التنفيذ أو الربح. لا يفترض التنفيذ بسعر إغلاق تمت ملاحظته بالفعل بعد اكتمال إشارة اليوم. تحتاج وحدات تجزئة الأسهم وتوقيت توفر المعلومات والمكونات والأحداث التاريخية إلى أدلة.

لم تُفعّل منحنيات جديدة لإعادة المعايرة الصارمة لفترتي5/8جلسات بسبب نقص العينات التاريخية المتحقق من توقيتها. القيم القديمة مراجع بحثية غير متحققة. لم تثبت المقارنات التاريخية للقواعد الثابتة توقعاً موجباً مستقراً؛ والتاريخ الذي سبق فحصه ليس مجموعة اختبار لم تُمس. نجاح اختبارات البرمجيات لا يثبت غياب كل تسرب للمعلومات أو الإفراط في الملاءمة.

## التحديث والتحقق والتطوير

أصلح تحديث20أكتوبر الهوية، ومحاسبة التجزئة، وتوقيت الأدلة التاريخية، وإصدارات الأحداث، وصدق المعايرة وأخطاءCI. نجح الإصدار المنشور`162054e` في3321اختباراً و45اختباراً فرعياً، مع تخطي حالتين موجودتين. راجع شارةCI لأحدث إصدار، ولا تعتبرها إثباتاً لأداء التداول.

[سجل التغييرات](CHANGELOG.md) بالإنجليزية · [سجل التحقق](PUBLIC_RELEASE.md) بالصينية · [تفاصيل الإصلاح](wiki/RELEASE_20261020_ZH.md) بالصينية · [منهجيةCall](wiki/CALL_PLAN_RESEARCH_ZH.md) بالصينية

يتطلب التطويرPython3.11+ وNode.js20+. اضبط وجهةAPI بواسطة`VITE_API_URL`.

<div dir="ltr">

```sh
python -m pip install -e ".[dev]"
pytest --ignore=agent/tests/e2e_backtest --ignore=agent/tests/test_e2e_harness_v2.py --tb=short -q
cd frontend
npm ci
npm run build
```

</div>

اختباراتE2E ذات النماذج الحقيقية تحتاج تفعيلًا صريحًا واعتماداً منفصلًا. لا تربط وحدات تخزين الإنتاج بالاختبارات المعزولة.
