## 修复了什么

| 原问题 | 本次处理 | 仍然存在的边界 |
| --- | --- | --- |
| 下一日行情参与删除过去价格 | 只按当时已知数据判断质量 | 以前已删除的数据不会自动恢复 |
| 用全历史均值定义过去的超额收益 | 基线只包含信号当日已经成熟的历史收益 | 旧标签/旧曲线不会自动获得可信认证 |
| 当日收盘收益影响当日开盘配置 | 组合优化和开盘决策隔离可用时点 | 不证明任意用户策略也不存在未来信息 |
| 同行回放使用截止日之后资料 | 截断行情并过滤明确晚于截止日的资料 | 缺真实发布时间的资料仍未认证 |
| 旧浪形确认后回填过去买卖点 | 按首次可以确认的日期输出 | 形态本身不代表盈利能力 |
| 训练标签跨入测试期 | 整日分组、标签成熟检查与purge | 历史试验次数与数据质量仍影响可信度 |
| 使用样本内结果自动启用校准 | 新构建只保存研究候选，门槛未通过不启用 | 旧线上研究概率仍需独立验证 |
| 空期权链被算成GEX覆盖或产生虚假Flip | 缺失/非有限OI不计覆盖，全零曲线不造拐点 | 不解决供应商授权或交易所数据缺口 |

## 新增前向版本对账

入口：回调买入榜 → 兑现对账 → 按冻结版本与持有窗口对账。

新记录保存生成榜单时实际使用的参数/配置、公式身份、校准曲线或fallback来源及收益口径版本。首次预测不可覆盖；同一版本跨日累计，不同版本、持有窗口、前向/回放分别统计。旧记录缺版本就显示待审计，不用当前配置补历史。

默认新口径为记录后下一可交易开盘入场，持有指定交易日后开盘结算。旧模型概率对应信号日收盘到未来开盘，两者不能直接作为同一概率目标比较；新口径的预测概率、Brier和可靠性留空，实际净收益/自身超额仍可按成熟记录统计。

日期或样本不足时区间留空；版本信息完整不代表策略有效。研究事件平均收益不是账户资金曲线，正股方向或超额命中也不是期权达到目标的概率。

## 真实验证没有支持上线新模型

修复后重新生成事件，主8日与短线5日分别比较固定校准候选，以三个时间验证折选模型，最终历史测试不用于挑参数。两个窗口均未胜过训练基准率概率，排序单调性未成立，Top20净收益及自身超额的区间均跨0。新候选没有替换旧曲线。

历史测试期间已被更早研究查看过，不能声称是从未看过的holdout；稀疏成分档案、退市样本、复权和企业行动仍未完整认证。后续应冻结假设，在真实新日期上前向验证，不围绕已看测试反复调参。

离线示例（缓存及成分归档须自行合法准备，仓库不附带真实行情）：

```bash
python agent/scripts/validate_causal_calibration.py \
  --data-root /path/to/your/cache \
  --protocol agent/data/causal_calibration_protocol.example.json \
  --output /path/to/new/research-output
```

示例历史窗口已经被查看，`unseen_holdout=false`不得为了通过门槛而改成true。示例只演示输入结构；不同来源、覆盖与成本下的结果可能不同。
