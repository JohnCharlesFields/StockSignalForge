# StockSignalForge：品牌恢复与历史证据修复

## 项目定位

**StockSignalForge：AI股票研究工作台，基于HKUDS/Vibe-Trading框架构建，整合查行情、看新闻、筛选回调候选、研判个股、持仓复盘、策略回测等功能的一站式平台。**

页面标题、侧栏与 README 恢复独立品牌 **StockSignalForge**，slogan 为 **easymoneysniper**。聚源仍是可选数据接入，授权和能力见 [接入说明](../GILDATA_MCP.md)；研究结果保留真实来源标注，不把数据供应商写成收益背书。保留上游署名及 MIT 许可，不迁移现有数据库或环境变量。

## Bug 原因与修复

| 问题 | 修复 | 仍需注意 |
| --- | --- | --- |
| 拆股前后单价直接比较产生虚假巨亏或盈利 | 按已核验生效日向前转换股数、止损、目标、成本与事件退出单位 | 行动目录覆盖有限，无法核验的跳变标为未知；不是自动识别全部公司行动 |
| 成员文件日期被误当作历史实际可知时间 | 有时区的真实采集时间、不可变多版本、生效日逐次变更校验 | 事后重建不天然证明当时可知，缺证据不回退今天成分 |
| 当前事件主体/类别更正影响过去退出 | 保留完整历史版本和当时已知字段，旧局部记录不补造历史 | 财报与宏观历史覆盖不足不能视作无事件 |
| 只有未来结果完整的机会才进入名册 | 先冻结事前机会输入，再分别标记结算、缺失、跨区或未成熟 | 原种子和缓存股票集合仍限制覆盖，不宣称全市场独立信号普查 |
| 校准中的拆股、缺日、退出日后续价格污染标签 | 共用单位转换，成本保留原价口径；只使用实际成熟路径和退出开盘 | 股票收益标签不是期权盈利概率或账户净值 |
| 只读在线 WAL 数据库导致离线验证失败 | 显式读取独立闭合备份，拒绝把在线库当作 immutable 文件 | 不绕过在线数据库一致性要求 |
| 旧缓存仍显示“已验证”，8日口径误写10日 | 只读可信度视图统一降级未验证声明，并使用真实持有窗口 | 不改旧概率数值、排序权重、历史预测和快照 |

图表缩放范围在后台数据更新、切换指标及窗口调整后保留；缺失比例不显示为零、下行观察不冒充确认入场等前次修复一并保留。

## 首页校准状态

没有拟合或激活新曲线。旧数值保留作未验证研究参考，缺历史时点、生存者控制、公司行动、独立留出或账户回测证据时不显示本轮“已验证”。不重写历史预测，也不把交易正收益率移植进主榜概率。
