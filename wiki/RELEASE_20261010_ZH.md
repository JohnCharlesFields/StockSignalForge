# 2026-10-10 功能更新与 Bug 修复

本次为10月9–10日已完成工作的增量公开发布。保留上游许可与原有模型；不上传生产数据，不重启线上Docker，不连接券商或下单。

## 新功能

| 功能 | 使用方式与效果 |
| --- | --- |
| 实验性 v-swing 波段 | 个股日线开关显示买/卖标记、冻结入场/止损、+2R目标、+1R后下一交易日保本参考及研究仓位 |
| 新买点分组排序 | 回调榜优先最近完整交易日的新实验买点，同组按原收益校准概率排序；原流动性/深超卖筛选保留 |
| 波段持续监测 | 复用SQLite留存触发、冲突与集中度观察，参考位冻结；最多5个开放买参考，成熟前向样本足够后才允许每周有界调整 |
| 独立验证与开关 | 股票分组RF/逻辑回归比较、固定逐月滚动、成本/跳空/同根先止损与下一日入场敏感性；启用模型和启用排序可分别关闭 |
| 公司介绍与供应链 | 行业/一致预期融入公司资料，具体公司链接、关系状态、同日行业市值；按钮按需展示图谱和可取得的PE/三月价格变化 |
| 近期新闻一句总结 | 保留原展示，只增加简短归纳；明确只有标题还是有来源摘要，不把未读取正文当作已核验事实 |
| 60–90天Call情景 | 手动取得真实合约双边报价后比较成本、价差、Delta和退出情景；财报窗口与费用预算约束，不给伪造的盈利概率或最优卖点 |

## Bug 修复

| 问题 | 原因与处理 |
| --- | --- |
| 搜索个股慢、亚马逊搜不到 | 原查询路径同步维护目录并占写锁，单名称缺中文；改只读本地前缀/别名索引、后台维护、取消旧请求与短期缓存，保留多证券身份 |
| 一只异常代码使日批全部中止 | 空历史/异常索引先做日期比较引发TypeError；先检查、逐股隔离，保留拒绝原因与已完成结果 |
| 数据未发布被当作扫描失败 | 付费下载前检查供应商发布范围，区分等待数据、部分完成和真正失败；在合格新行情子集上推进，不用旧数据伪造当天结果 |
| 聚源新闻主角错归零售商 | 区分产品制造方与销售渠道；Mac促销主角应是Apple，Amazon作为次要实体；修正归属时保留阅读反馈并清除错误公司的行情 |
| 新闻现价/行业缺失 | 有界后台补齐优先读缓存，缺项批量请求既有源；价格注明日期，不用一根K线制造前收、ATR或预计开盘涨幅 |
| 公司关系空白像成功结果 | 区分更新中、失败、未披露并单独重试；泛称不当具体公司，上市身份不等于关系已核验；关系研究必须有实际读取的来源 |
| 博主页不更新、字幕卡住 | 先更新七位博主的视频元数据，再做有界字幕/总结任务；增加超时、冷却、进度及yt-dlp/EJS/Node环境。登录限制/无字幕仍明确提示，不能保证都取得 |
| 图上看不到目标线、旧点冒充今天 | 风险线纳入纵轴范围；过期快照不标新买点，冲突/集中度触发全部留存，完整榜单先排序再截取展示 |
| 期权缺字段被看作零、重试超预算 | OI/成交量未知保留为空；按交易日历取报价窗口，重试也占费用预算，自动OPRA默认费用上限0 |
