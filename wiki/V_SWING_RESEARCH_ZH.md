# v-swing 实验性波段研究

## 使用入口

- 回调买入榜 `/` 的“波段研究 · v-swing”：读取最近完成快照；“运行波段打分”手动执行，重复点击按活动线程去重。
- 个股研判 `/single-stock-overnight?symbol=AAPL` 的日线图：“波段买卖点 · 实验”开关。绿色买、红色卖；悬停区分时序回放与前向研究，均不是实际成交。
- 原日批完成候选落库后，异步调度一次波段任务；失败不影响原榜单/日批结果。页面打开不训练、不抓取新行情。

## 排名与概率

先排列**最新完整美股交易日的新实验买点**，同组按原收益校准概率降序，再按原优先级分打破相同概率。最新买点可以补入旧榜单未包含的标的，但必须有原校准概率；行情过期、身份未核验、买卖冲突、验证未通过者不标记当日买点。现有高流动性/深超卖显示过滤继续生效，可能隐藏新点。

`P(buy)` / `P(sell)` 是匹配手工标注的分类强度，**不是盈利胜率**。主榜概率保留原 pullback_hv 等收益校准口径（扣成本跑赢股票自身基线），不是 v-swing 赚钱概率。独立盈利概率校准样本不足时不替换、不伪造概率。

## 模型与数据边界

本地验证使用了132条私人复盘标注，**公开仓库不分发这些训练标注或行情数据**。公开版 `enabled=false`；`agent/config/v_swing_annotations.example.json` 为空模板。自行准备合法来源的缓存日线，以及 `agent/config/v_swing_annotations.json`（已忽略），格式为 `{"证券代码": {"YYYY-MM-DD": "buy或sell"}}`，完成离线审计后才启用。标注为空时明确报 `v_swing_private_annotations_required`，不制造结果。

参考方法文本称16个特征，但明确列出的顺序实际为17个，按这17个实现。因果收益率、EMA5/10/15/20距离及斜率、多空排列、Wilder RSI14、20日高低位置、相对成交量；只用信号日及以前日线。股票分组测试使用合成输入，不依赖私人标注。

独立买/卖随机森林：400棵树、深度6、balanced_subsample、seed7；阈值为训练概率90分位 × mult，上限0.95。mult限定0.7–1.6。每次打分先验证再重训一次，页面只读快照。训练输入/配置/交易日指纹变化则拒绝发布旧验证结果。

复用已有日线缓存和SQLite，不新增抓取层、不请求收费行情、不调用大模型、不连接券商。SKHY/SPCX的标注身份与历史对应尚未核验，保留原始标注但不训练/触发，不能静默替换代码。LLY和原统一报告股票池可用训练模型打分；≥60根且最新日等于最近完整交易日才有效。

## 风控与持续监测

参考入场=信号收盘；ATR14为真实波幅近14日均值；止损=min(20日低点×0.995, 入场−2ATR)，止盈=入场+2R。箱体宽度<12%，止损距离>10%提示过远，14日内财报提示临近；财报缓存缺失标未知，不当作无风险。

7日内同方向开放信号冻结原入场/止损/止盈，只更新强度。+1R保本调整最早下一交易日生效，同根先后不可知按止损优先；跳空按开盘价而非保证止损价。开放买信号最多5个，新批按匹配强度取可用名额，其余观察。卖信号仅为已有多头离场参考，不做空；同日买卖冲突不新增持仓参考。

SQLite使用独立 `v_swing_signals` / `v_swing_adapt_state`（避免与已有信号表冲突）。历史回放不写入前向信号库，不用于每周自适应。每周仅使用至少10个交易日龄的真实前向研究信号结算，最近20笔不足时mult不动；满足原提示词40%/50%/3%规则才调整，同周去重。

## 验证与限制

按股票GroupKFold，RF和标准化逻辑回归双探针；精确率、召回率、F1、PR-AUC对比标注占比，按整只股票bootstrap，EMA类重要性与深度3树规则可审计。另固定逐月训练截止/测试窗口，训练不读未来标注；盈利校准训练样本退出日必须早于测试起点。

主执行用次日开盘，另列次日收盘敏感性，均扣0.1%每轮成本。现金约束研究组合单笔1%风险、单笔资金≤20%、最多5个开放仓位，不将重叠交易平均收益冒充账户资金曲线；比较标注证券等权持有，不是SPY alpha。提示词引用的2022与2026业绩不当作本项目结果。

仍有复盘标注后视、未标注日并非确证负样本、现存证券幸存者偏差、缓存复权未经独立核验、小样本等限制。股票分组通过只表示手法具有EMA依据，不表示稳定盈利。历史回放与真实前向研究要分开阅读。

## 配置与回退

`agent/config/v_swing.json`：`enabled=false`关闭模型接入/图表；`rank_today_first=false`单独关闭新排序并恢复原基础榜单顺序。原缓存、历史信号与数据库不删除。修改配置后沿用现有Docker构建/发布；确认无活动扫描再重启，不使用 `down -v`。

```powershell
docker compose build vibe-trading
docker compose up -d --no-deps vibe-trading
```

离线验证：在已有Python依赖环境设置 `PYTHONPATH=agent`，运行 `python agent/scripts/validate_v_swing.py --output agent/runs/v_swing_audit.json`；只读现有缓存。生产手动打分使用认证的 `POST /v-swing/run`，读取 `GET /v-swing/status`。本报告为数据决策参考，不构成投资建议。
